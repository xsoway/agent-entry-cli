## Context

SDK 已拥有模型/工具循环；运行时已有元数据日志、预算和原子上下文提交。终端使用 PromptSession，普通模式却在线程内 input，SIGINT 后线程阻塞使退出卡住。已有样式和中文文档改动需保留。

## Goals / Non-Goals

目标：修复所有已报告 P1/P2；通过元数据展示执行生命周期。非目标：展示私有推理、自动重试、自动持久化、远程发布或迁移业务框架。

## Decisions

- 继续使用一个 SDK loop。Runtime.run 增加可选 on_event 观察回调，只接收允许字段的结构化元数据；EventLog 先写入，再 best-effort 通知观察者。观察者失败不改变业务执行结果，也不记录异常正文。
- 模型调用前后、工具开始/结束/拒绝/失败/取消、摘要准备及最终提交、清理与结束均发安全事件。只处理公开答复 text delta，不转发 reasoning 事件。错误仅映射固定原因码；模型原始异常正文不展示。
- 用异步 fd 行读取替代普通模式线程 input，并显式管理终端会话期间的 SIGINT。第一次运行中中断取消，第二次请求退出；不得绕过清理或把未知写当成功。
- 中文提示与错误集中放入轻量 presentation 模块；终端保留渲染。增强模式动态工具栏显示耗时/阶段/调用预算，普通模式仅按阶段打印安全事件。
- /context 显示历史、指令、工具 schema 的估算和预留；实际请求准入仍以 MeteredModel 计算为准。自动摘要阈值包含指令与工具 schema，避免历史看似未满但实际请求超限。
- /sessions 使用文件 mtime 排序，不更改检查点 schema；仅显式列出已保存摘要的目标/任务预览，/resume latest 不自动恢复。旧 ID 与不可变文件兼容。
- 命令表补齐 /stop /exit /tools 和项目自定义命令；运行中仅允许停止、退出和下一轮文字，不排队执行其他控制命令。

## Risks / Trade-offs

- 非协作插件仍可阻止 Python 退出；状态必须显示清理未完成，不能承诺强制取消。
- 文件修改时间不等于真实业务时间；摘要列表明确为本地保存时间，不持久化额外身份信息。
- 默认不保存跨进程输入历史，保留已有隐私约定；预览仅来源于已经显式保存的摘要。
- 模型端点兼容性不由元数据观察测试证明；通过真实 SDK 脚本模型与真实 PTY 验证，真实端点可用时另执行隔离场景。

## 独立审查修正

- 阶段事件可能先于 SDK 文本消费者完成，不能刷新脱敏尾串；仅在文本生命周期最终收尾时刷新。
- 显式记录尚未完成计量的模型调用；provider finalizer 超时期间仍记未知，不能以 finally 尚未执行推断为零。
- PromptSession 使用 handle_sigint=False，SIGINT 由会话统一管理，避免 prompt 结束时移除原处理器。
- 成功切换项目后重建内存编辑器；失败切换保留原输入历史。
