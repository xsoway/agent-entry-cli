                        01 / THE EXECUTION PATH
                        

                            一个循环，各自负责。
                        

                    

                    

                        SDK 驱动唯一的模型与工具循环。Runtime
                            管理准入、预算与清理，项目逐次判断业务权限。
                    

                

                

                    

                        01项目绑定显式选择 Project 与可信插件
                    

                    

                        02上下文准入检查窗口、历史、schema 与预留
                    

                    

                        03模型循环模型与工具往返使用同一循环
                    

                    

                        04项目授权逐次检查；写操作默认拒绝
                    

                    

                        05清理与返回取消收尾，返回状态与元数据
                    

                

                

                    流程高亮用于解释执行路径，不代表正在运行
                        Agent。未知写结果由项目核实，不自动重放。

                            Agent。

                    03 / SMALL SURFACE, EXPLICIT BEHAVIOR
                    

                        接得进去，边界也看得见。
                    

                    

                        Alpha 阶段，API
                            保持小而明确。插件是可信的本地代码，不是操作系统沙箱。
                    

                    
                

                

                    

                        01
                        

                            

                                异步业务工具
                            

                            

                                用具名异步函数连接现有
                                    API。写工具每次调用都经过项目授权。
                            

                        

                    

                    

                        02
                        

                            

                                上下文与摘要
                            

                            

                                指令、schema、历史和预留共同参与窗口估算。只有显式
                                    /save 持久化摘要。
                            

                        

                    

                    

                        03
                        

                            

                                停止与会话控制
                            

                            

                                流式输出、队列暂停、项目作用域隔离。清理未完成时阻止新轮次。
                            

                        

                    

                    

                        04
                        

                            

                                安全执行元数据
                            

                            

                                通过 on_event
                                    接出阶段、耗时与已知／未知用量。私有推理正文不进入界面与默认账本。
                            

                        

                    

                

            

            

                

                    

                        04 / GET STARTED
                        

                            先接一个只读工具。
                        

                    

                    

                        macOS / Linux，Python 3.13+ 与
                            uv。模型和凭据由你配置；本页不发出模型请求。
                    

                

                

                    

                        

                            

                                LOCAL CHECKOUT / SHELL
                            

                            
uv sync --locked --extra dev
uv run --locked agent-entry --help
uv run --locked agent-entry --diagnostics

                        

                        

                            在本地源码目录运行。诊断无需凭据；真实对话前设置环境变量中的模型与
                                API key，CLI 不自动加载 .env。
                        

                        

                            

                                PROJECT API
                            

                            
from agent_entry_cli import Project, Tool, run_cli

# existing_api: your named async function
project = Project(root=project_root,
                  tools=(Tool(existing_api),))
run_cli(project)

                                片段仅展示接口；完整可运行插件见接入说明。
